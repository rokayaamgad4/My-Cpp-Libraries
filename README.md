# My C++ Libraries

A personal collection of reusable C++ header files, with utility functions organized into separate namespaces. Built as part of my C++ learning journey.

## Libraries

| File | Description |
|------|-------------|
| `MyInputLib.h` | Input reading and validation |
| `MyRandomLib.h` | Random numbers, characters, words, and keys |
| `MyArrayLib.h` | Array manipulation and utilities |
| `MyMathLib.h` | Math and number-related functions |

## Usage

Copy the header into your project and include it:

```cpp
#include "MyMathLib.h"
```
